## 规格与可用范围

阿里云公布 Qwen4‑Max 的混合专家架构有 2.4 万亿总参数，每个词元激活约 710 亿参数，上下文窗口为 100 万词元。首发渠道包括 QwenCloud 的 API 和 Token Plan，以及 QwenWork、QwenStudio。公告同时预告了较小的开放权重型号，Max 条目记录的是已公布的服务入口。

## 为什么值得关注

原生视觉输入和长上下文让代码、界面截图和业务文档可以放进同一个任务。阿里云在自有 Work360 上报告，相比 Qwen3.8‑Max，高推理设置下所需词元减少约 35%，平均任务成本下降约 60%。这些数字适用于该测试口径，适合用真实文件和代码库复测。
