## 规格与可用范围

阿里云公布 Qwen4‑Max 的混合专家架构有 2.4 万亿总参数，每个词元激活约 710 亿参数，上下文窗口为 100 万词元。首发渠道包括 QwenCloud 的 API 和 Token Plan，以及 QwenWork、QwenStudio。公告同时预告了较小的开放权重型号，Max 条目记录的是已公布的服务入口。

## 为什么值得关注

原生视觉输入和长上下文让代码、界面截图和业务文档可以放进同一个任务。阿里云在自有 Work360 上报告，相比 Qwen3.8‑Max，高推理设置下所需词元减少约 35%，平均任务成本下降约 60%。这些数字适用于该测试口径，适合用真实文件和代码库复测。

## 具体改动

- 官方公布 2.4T 主干参数、原生视觉和 100 万 token 上下文。模型使用 Gated DeltaNet 与 Qwen Sparse Attention 处理长序列，引入门控残差和 N-gram embedding。
- 发布侧重点是专业工具使用和长任务交付。官方用相同测试套件对比 Qwen3.8-Max，报告了部分设置下的 token 用量下降。
- 首发通过 QwenCloud 的 API 或 Token Plan 接入，官方公告将计划公开的小模型与已可调用的 Max 区分开来。

## 影响与验证

先用同一份截图、长文档和工具任务对比旧版与新版本，记录长文内容定位、工具参数正确率、输出质量和完成时间。百万上下文的实际请求预算需结合所用接口和输出要求。
