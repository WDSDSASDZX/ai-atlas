## 具体改动

- Agent v2 可配置 Output Routes，让 Agent 根据路由条件选择下游分支。普通文本节点可以流式输出，路由和结构化结果仍缓冲。
- Workflow 与 Chatflow 的 `.ifpkg` 可以携带内嵌 Agent、Skill 和文件，导入目标工作区时重新绑定引用。
- 工作流工具作为子图运行，可从控制台查看子步骤并协调暂停、继续和停止。Agent Knowledge Base 作为需显式启用的 Beta 功能，包含单独的服务和数据库要求。

## 影响与验证

自托管升级需要同步更新 API、worker、Agent Backend 与 runtime，源码安装要求 Python 3.13。先验证旧 Agent 快照能读取、两条路由都可达，以及运行中的子流程能正常停止。
