## 具体改动

- 外部追踪把已持久化的子步骤放在对应的 Workflow Tool span 下，便于区分重复调用、错误和不同层的 LLM 上下文。丰富层级从升级后的执行开始记录。
- 应用导出默认使用 `.ifpkg` v2，可以携带绑定版本及传递依赖。导入会复用目标工作区已有的工具，并重建缺失依赖。
- Agent 配置文件支持并行上传和预览；OpenAPI 和 `difyctl` 新增工作区 Skill 的查看、导入、导出与发布。

## 影响与验证

跨环境迁移前，用测试工作区导入一个带两层子工作流的包，验证依赖指向和调用结果。滚动升级时新旧追踪队列要分开处理，新队列默认 `ops_trace_v2`，等旧任务全部处理完再撤下旧消费者。
