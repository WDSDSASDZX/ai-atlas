一个网关统一管理会话后，终端、桌面和 Web 可以访问同一份历史。对多端使用来说，这是比新增模型选项更实际的更新。Web 工作台在该版默认关闭，详情见发布说明。

## 状态归属与接入

网关把会话、请求队列和历史放在同一个进程管理，CLI、TUI、桌面和其他接口作为客户端连接到它。旧模式下多个入口分别运行实例，可能出现消息重复或缺失。Web 工作台由网关服务，Docker 与 Nix 构建包含该入口，默认关闭。

## 升级怎样验证

使用同一个会话从终端和网页交替发送，再做两端同时发送、断线重连和网关重启。按消息 ID 核对顺序、重复和上下文。对需要公开访问的场景单独核对身份登录、反向代理与会话权限，测试任务使用无敏感数据的账号。
