该版的 Inkling 2 Mini 支持范围是 Apple 芯片。准备在其他设备部署时，先查本机平台是否受支持。

## 具体改动

- Inkling 2 Mini 支持文本与图像输入、工具调用和思考，Ollama 发布说明给出的 Mac 内存参考约为 20 GB。该版本的此模型支持限定为 Apple Silicon。
- Apple Silicon 可并发处理多个请求。启动 Claude Code 时可按需加载 MCP 工具，启动 OpenCode 时会从模型元数据设置思考选项。
- Vulkan 在集成 GPU 上使用内存映射，改善共享内存设备加载失败；Windows 核显部分卸载模型时的 KV 缓存分配也有修正。API 传入工具定义里的额外 JSON Schema 关键字会保留。

## 影响与验证

在 Mac 上先跑单请求，再同时跑两个独立会话，记录首 token 和峰值统一内存。Windows 核显可用之前加载失败的同一模型复测。把工具输出的 JSON Schema 校验纳入回归。
