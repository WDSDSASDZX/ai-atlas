## 使用场景

一项功能可能需要同时改前端、服务端和文档。Copilot Projects 的公开预览把相关仓库和工作上下文集中到项目里，代理可以返回供审核的结果，包括拉取请求。项目级自动化也可承接重复流程。

同次更新还公布了桌面应用操作能力的公开预览。评估这类功能时，可以先用一个跨仓库的小任务检查上下文传递、权限设置以及最后需要人工审核的内容。
