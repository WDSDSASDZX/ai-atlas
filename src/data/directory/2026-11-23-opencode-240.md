桌面版可以在同一工作区保留浏览器会话。定时自动化适合在已授权范围内重复执行日常检查。升级前可留意发布页列出的插件更新和已有权限规则变化。

## 具体改动

- 桌面版增加内嵌浏览器和持久化配置。终端 UI 使用新设计作为默认，旧配色可选 `opencode-classic`。
- GitHub Copilot 不再读取 `GITHUB_TOKEN`，可以通过 `COPILOT_GITHUB_TOKEN` 或 OAuth 接入。未指定 MCP 协议时，先尝试新版握手，再回到 legacy。
- 图像工具由 `experimental_image_generate` 改名为 `generate_image`，旧权限规则会映射，已记住的长期允许需重新确认。TUI 插件要求 OpenTUI 0.9.4 或更高。

## 影响与验证

升级前先固定团队内部插件版本，升级后检查登录、模型切换、一次工具审批和一个自定义 TUI 插件。若桌面和服务器分开升级，还要验证远端服务支持所用桌面功能。
